## 安装说明

### 飞牛 fnOS（FPK 安装包）

1. 下载对应架构的 `.fpk` 文件；
2. 打开飞牛 fnOS「应用中心 → 手动安装」，选择该文件并安装；
3. 安装完成后打开应用，浏览器访问 `http://<飞牛IP>:16080`。

### Docker（在线部署包，需联网）

1. 下载 `tianshu-nav-v1.1.010.zip` 并解压；
2. 启动服务：`docker compose up -d`（首次启动自动拉取基础镜像，需联网）；
3. 浏览器访问 `http://<主机IP>:16080`（默认端口可在 `docker-compose.yml` 中修改冒号左侧端口）。

### Docker（离线部署包，含镜像）

1. 下载对应架构的 zip 并解压；
2. 导入镜像：`docker load -i tianshu-nav-image.tar`；
3. 启动服务：`docker compose up -d`；
4. 浏览器访问 `http://<主机IP>:16080`（默认端口可在 `docker-compose.yml` 中修改冒号左侧端口）。

## 功能特性

用户管理（注册 / 登录 / 找回密码 / 防爆破锁定）、邀请码注册、分组站点导航（内外网双地址、拖拽排序）、内外网自动切换、站点图标自动拉取与公共图库、站内通知、个人收藏、日期天气搜索首页、暗黑 / 浅色 / 跟随系统三档主题、数据 JSON 导出导入与浏览器书签导入、在线升级与一键回滚、免费版 / 专业版订阅授权、Chrome / Edge 浏览器插件（MV3）、PWA 多终端适配。

## 升级与备份

- 管理后台「系统设置 → 更新源」配置 JSON 更新源后，首页「系统升级」可在线检测升级；
- 升级包上传自动白名单校验与旧文件备份，支持一键回滚；
- 手动备份：直接备份数据目录 `./data`（含数据库、图标、备份、缓存）。
